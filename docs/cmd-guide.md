## 1. 页面布局

CMD 控制台页面分为两个区域：

```
┌─────────────────────────────────────────────────────┐
│  顶部操作栏：[实时终端] [添加快捷命令] [脚本编辑器]      │
├─────────────────────────────────────────────────────┤
│                                                     │
│  快捷命令区域（卡片网格）                               │
│  ┌──────┐ ┌──────┐ ┌──────┐                        │
│  │命令1  │ │命令2  │ │命令3  │                        │
│  └──────┘ └──────┘ └──────┘                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- **实时终端**：点击按钮以弹窗形式打开，支持实时流式输出
- **快捷命令**：以卡片网格展示，点击"运行"直接执行
- **脚本编辑器**：进入专业脚本编辑器页面，提供语法高亮、代码补全、错误诊断等功能

> **提示**：MiniScript 脚本通过"快捷命令"功能管理，也可在「脚本编辑器」中编写并保存。

## 2. 快捷命令

### 2.1 添加快捷命令

1. 点击页面顶部的「添加快捷命令」按钮
2. 在弹窗中填写以下信息：
   - **名称**：命令的显示名称（必填）
   - **类型**：选择 `CMD 命令` 或 `MiniScript 脚本`
   - **内容**：CMD 命令或脚本代码（必填）
   - **描述**：简短说明（可选）
   - **排序**：数字越小越靠前（可选）
3. 点击「保存」

### 2.2 编辑快捷命令

点击命令卡片右上角的编辑图标（铅笔），修改后保存。

### 2.3 删除快捷命令

点击命令卡片右上角的删除图标（垃圾桶），确认后删除。

### 2.4 运行快捷命令

点击命令卡片底部的「运行」按钮：

- **CMD 命令类型**：自动打开终端弹窗，流式显示输出
- **脚本类型**：在前端直接解释执行，输出显示在终端弹窗中

### 2.5 命令类型说明

| 类型 | 标签颜色 | 执行位置 | 说明 |
|------|----------|----------|------|
| CMD 命令 | 绿色 | 服务端 | 原始 Shell 命令，通过 SSE 流式返回输出 |
| MiniScript 脚本 | 紫色 | 浏览器 | 前端解释执行，可通过 `cmd()` 调用服务端命令 |

## 3. 实时终端

### 3.1 打开终端

点击页面顶部的「实时终端」按钮，以弹窗形式打开终端。

### 3.2 执行命令

在底部输入框中输入命令，按 `Enter` 或点击发送按钮执行。命令通过 **SSE（Server-Sent Events）** 流式返回输出，实时逐行显示。

### 3.3 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 执行命令 |
| `↑` | 上一条历史命令 |
| `↓` | 下一条历史命令 |
| `Ctrl + L` | 清屏 |

### 3.4 清屏

点击输入框右侧的垃圾桶图标清除终端内容。

### 3.5 关闭终端

点击终端弹窗右上角的关闭按钮，或点击弹窗外部区域。

## 4. MiniScript 脚本语言

MiniScript 是一种类 Python 语法的极简脚本语言，全部在浏览器内解释执行。

### 4.1 变量赋值

```python
x = 10
name = "hello"
flag = true
nothing = null
```

### 4.2 算术运算

```python
a = 10 + 5        # 15
b = 10 - 3        # 7
c = 4 * 6         # 24
d = 20 / 4        # 5
e = 17 % 5        # 2
f = (2 + 3) * 4   # 20
```

### 4.3 字符串拼接

```python
name = "World"
msg = "Hello, " + name + "!"    # "Hello, World!"
```

### 4.4 比较运算

```python
5 == 5       # true
5 != 3       # true
10 > 5       # true
3 < 7        # true
5 >= 5       # true
4 <= 3       # false
```

### 4.5 逻辑运算

```python
true && false     # false
true || false     # true
!true             # false
5 > 3 && 10 < 20  # true
```

### 4.6 条件判断（if / elif / else）

支持两种写法：

**内联写法**（单语句）：

```python
x = 10
if x > 5: print("big")
else: print("small")
```

**缩进块写法**（多语句）：

```python
x = 10
if x > 5:
    print("big")
    print("very big")
else:
    print("small")
```

**多分支 `elif`**（推荐，避免深层嵌套）：

```python
score = 85
if score >= 90:
    echo("优秀")
elif score >= 80:
    echo("良好")
elif score >= 60:
    echo("及格")
else:
    echo("不及格")
```

`elif` 可以连续出现任意多次，等价于嵌套的 `if/else`，但代码更扁平、更易读。`elif` 必须跟在 `if` 块之后，且可省略末尾的 `else`。

**嵌套条件**：

```python
x = 15
if x > 10:
    if x > 20:
        print("huge")
    else:
        print("medium-large")
else:
    print("small")
```

> **注意**：缩进必须一致（推荐 4 个空格），不能混用空格和 Tab。

### 4.7 循环

#### while 循环

```python
i = 0
while i < 5:
    print(i)
    i = i + 1
```

支持 `break` 和 `continue`：

```python
i = 0
while i < 10:
    i = i + 1
    if i == 5:
        continue   # 跳过 5
    if i == 8:
        break      # 到 8 就退出
    print(i)
```

#### for 循环（for...in）

遍历数字范围使用 `range()` 函数：

```python
# range(end): 0 到 end-1
for i in range(5):
    echo("第 " + str(i) + " 次")

# range(start, end): start 到 end-1
for i in range(2, 6):
    print(i)       # 2, 3, 4, 5

# range(start, end, step): 带步长
for i in range(0, 10, 2):
    print(i)       # 0, 2, 4, 6, 8

# 反向遍历
for i in range(5, 0, -1):
    print(i)       # 5, 4, 3, 2, 1
```

遍历字符串：

```python
for ch in "hello":
    echo(ch)
```

`for` 循环同样支持 `break` 和 `continue`：

```python
for i in range(100):
    if i > 5:
        break
    echo(str(i))
```

### 4.8 注释

```python
# 这是行注释
x = 10  # 行尾注释也支持
```

### 4.9 列表（List）

#### 创建列表

```python
nums = [1, 2, 3, 4, 5]
names = ["Alice", "Bob", "Charlie"]
mixed = [1, "hello", true, null]
empty = []
nested = [[1, 2], [3, 4]]   # 嵌套列表
```

列表元素可以是任意类型，支持尾随逗号 `[1, 2, 3,]`。

#### 索引访问

```python
nums = [10, 20, 30, 40, 50]
print(nums[0])    # 10
print(nums[2])    # 30

# 负索引（从末尾倒数）
print(nums[-1])   # 50  （最后一个）
print(nums[-2])   # 40  （倒数第二个）
```

字符串也支持索引访问：

```python
s = "hello"
print(s[0])       # 'h'
print(s[-1])      # 'o'
```

#### 列表拼接

```python
a = [1, 2]
b = [3, 4]
c = a + b          # [1, 2, 3, 4]
```

#### for 循环遍历列表

```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

# 配合 range 遍历索引
nums = [10, 20, 30]
for i in range(len(nums)):
    print("索引 " + str(i) + ": " + str(nums[i]))
```

#### 列表内置函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `append(list, ...items)` | 追加元素到末尾 | `append(a, 3, 4)` |
| `push(list, item)` | 追加元素，返回新长度 | `n = push(a, 5)` |
| `pop(list, index?)` | 弹出元素（默认末尾） | `pop(a)` / `pop(a, 0)` |
| `slice(list, start, end?)` | 切片（返回新列表） | `slice(a, 1, 3)` |
| `join(list, sep?)` | 列表转字符串 | `join(["a","b"], "-")` |
| `reverse(list)` | 反转（返回新列表） | `reverse([1, 2, 3])` |
| `sort(list)` | 排序（返回新列表） | `sort([3, 1, 2])` |
| `contains(obj, item)` | 是否包含 | `contains([1,2,3], 2)` |
| `len(list)` | 获取长度 | `len([1, 2, 3])` |

**示例**：

```python
# 动态构建列表
nums = []
for i in range(5):
    append(nums, i * i)
print(nums)        # [0, 1, 4, 9, 16]

# 弹出最后一个元素
last = pop(nums)
print(last)        # 16
print(nums)        # [0, 1, 4, 9]

# 切片
sub = slice(nums, 1, 3)
print(sub)         # [1, 4]

# 排序和反转
print(sort([3, 1, 2]))       # [1, 2, 3]
print(reverse([1, 2, 3]))    # [3, 2, 1]

# 列表转字符串
print(join(["2024", "01", "15"], "-"))   # 2024-01-15
```

### 4.10 函数调用

## 5. 内置函数参考

### 5.1 弹窗交互

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `alert(title, message)` | 标题, 内容 | `true` | 弹窗提示 |
| `prompt(title, message)` | 标题, 提示语 | 字符串 | 弹窗获取用户输入 |
| `confirm(title, message)` | 标题, 内容 | `true`/`false` | 确认弹窗 |

### 5.2 CMD 命令执行

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `cmd(command)` | 命令字符串 | 完整输出字符串 | **流式**执行，实时输出到终端 |
| `cmd_sync(command)` | 命令字符串 | 输出字符串 | 同步执行，一次性返回 |
| `echo(message)` | 消息 | 消息 | 输出到终端（紫色脚本标识） |

### 5.3 字符串与正则

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `regex(str, pattern)` | 字符串, 正则 | 匹配数组或 `null` | 正则匹配 |
| `regex_test(str, pattern)` | 字符串, 正则 | `true`/`false` | 正则测试 |
| `str(val)` | 任意值 | 字符串 | 转字符串 |
| `len(obj)` | 字符串/数组/对象 | 数字 | 获取长度 |

### 5.4 类型转换

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `parseInt(str)` | 字符串 | 整数 | 字符串转整数 |
| `parseFloat(str)` | 字符串 | 浮点数 | 字符串转浮点数 |
| `now()` | 无 | 整数 | 当前时间戳（秒） |

### 5.5 循环与迭代

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `range(end)` | 结束值 | range 对象 | 生成 0 到 end-1 的整数序列 |
| `range(start, end)` | 起始, 结束 | range 对象 | 生成 start 到 end-1 的整数序列 |
| `range(start, end, step)` | 起始, 结束, 步长 | range 对象 | 带步长的整数序列，支持负步长反向 |

### 5.6 列表操作

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `append(list, ...items)` | 列表, 元素 | 列表 | 向列表追加多个元素（原地修改） |
| `push(list, item)` | 列表, 元素 | 数字 | 追加元素，返回新长度 |
| `pop(list, index?)` | 列表, 索引? | 元素 | 弹出元素（默认末尾，支持负索引） |
| `slice(list, start, end?)` | 列表/字符串, 起始, 结束? | 新列表/字符串 | 切片 |
| `join(list, sep?)` | 列表, 分隔符? | 字符串 | 列表转字符串 |
| `reverse(list)` | 列表 | 新列表 | 反转（不修改原列表） |
| `sort(list)` | 列表 | 新列表 | 排序（不修改原列表） |
| `contains(obj, item)` | 列表/字符串/对象, 元素 | true/false | 是否包含元素 |

### 5.7 定时任务

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `set_timeout(code, ms)` | 代码字符串, 毫秒 | 定时器 id | 延迟指定毫秒后执行代码（只执行一次） |
| `set_interval(code, ms)` | 代码字符串, 毫秒 | 定时器 id | 每隔指定毫秒重复执行代码 |
| `clear_timer(id)` | 定时器 id | 无 | 取消定时器（可同时取消 setTimeout 和 setInterval） |

> **注意**：定时任务在浏览器中运行，关闭页面后自动停止。第一个参数为要执行的代码字符串。

**示例**：

```python
# 3 秒后执行一次
set_timeout("echo('3秒到了')", 3000)

# 每秒打印一次（用全局变量计数）
# 注意：每次定时器执行都会创建新的解释器实例
# 如需共享状态，建议使用 for/while 循环 + sleep
```

> **提示**：如果需要更复杂的定时逻辑（如共享变量、条件停止），推荐使用 `for` 循环 + `sleep()` 组合，这样所有代码在同一个解释器实例中运行，变量可以共享。

```python
# 推荐：循环 + sleep 方式
for i in range(10):
    echo("第 " + str(i + 1) + " 秒")
    sleep(1000)
```



## 7. 常见问题

### Q: 命令执行超时怎么办？

实时终端默认超时 300 秒，最大 600 秒。超时后进程自动终止。如果命令需要更长时间，建议拆分为多个短命令。

### Q: 脚本报错 "缩进错误"？

MiniScript 使用 Python 风格的缩进。请确保：
- 同一代码块内缩进一致
- 不要混用空格和 Tab
- 推荐使用 4 个空格缩进

### Q: `cmd()` 和 `cmd_sync()` 有什么区别？

- `cmd()` — 流式执行，输出实时显示在终端，适合长时间运行的命令
- `cmd_sync()` — 同步执行，一次性返回所有输出，适合快速命令

### Q: 脚本可以保存为快捷命令吗？

可以。添加快捷命令时，类型选择「MiniScript 脚本」，将脚本代码粘贴到内容区域即可。保存后可一键运行。

### Q: 非管理员可以使用 CMD 控制台吗？

不可以。所有 `/admin/cmd/*` 路由均需要管理员权限，非管理员访问返回 403。

### Q: 循环会无限运行吗？

不会。MiniScript 有多层保护机制：

1. **循环迭代上限**：`while` 和 `for` 循环最大 **100,000 次迭代**，超过会抛出错误
2. **脚本超时保护**：任何脚本最多执行 **30 秒**，超时自动中止
3. **UI 让出**：每 100 次迭代让出一次执行权（`setTimeout(0)`），避免阻塞浏览器
4. **手动中止**：脚本运行时终端标题栏显示红色「中止」按钮，点击可立即停止

```
while 循环超过最大迭代次数 100000，可能存在无限循环
```

```
脚本执行超时（30秒），已被自动中止
```

### Q: 如何停止正在运行的脚本？

脚本运行时，终端标题栏会出现红色「中止」按钮。点击即可停止脚本执行和所有定时器。

其他停止方式：
- **关闭终端弹窗**：自动中止脚本并清理所有定时器
- **运行新脚本**：自动中止当前脚本并清理定时器

### Q: `set_interval` 创建的定时器会一直运行吗？

脚本执行完毕后，如果仍有活跃的定时器，终端会提示「脚本已结束，但有定时器仍在运行」，中止按钮保持可见。点击中止按钮可停止所有定时器。

关闭终端弹窗也会自动清理所有定时器。

> **注意**：`set_interval` 最小间隔为 100ms，防止高频调用导致浏览器卡顿。定时器代码在独立上下文中执行，不会干扰主脚本的全局状态。

### Q: `cmd()` 和 `cmd_sync()` 会超时吗？

会。`cmd()` 超时时间为 15 秒，`cmd_sync()` 超时时间为 10 秒。超时后自动断开连接并返回已有输出。

### Q: 列表和 Python 列表有什么区别？

MiniScript 列表基于 JavaScript 数组，功能与 Python 类似但有差异：

- ✅ 支持 `[1, 2, 3]` 字面量、`list[0]` 索引、`list[-1]` 负索引
- ✅ 支持 `for...in` 遍历、`+` 拼接
- ❌ 不支持切片语法 `list[1:3]`（请用 `slice(list, 1, 3)` 函数）
- ❌ 不支持列表推导式 `[x for x in range(10)]`
- ❌ 列表方法是函数形式：`append(a, x)` 而非 `a.append(x)`

## 9. 错误信息与行号

MiniScript 的所有错误（语法错误和运行时错误）都包含**具体的出错行号和列号**，便于快速定位问题。

### 9.1 错误格式

错误信息统一格式：`第 N 行:M列：错误描述` 或 `第 N 行：错误描述`

### 9.2 语法错误（解析阶段）

在脚本开始执行前由 tokenizer / parser 抛出：

```
第 1 行:8：字符串未闭合（缺少 "）
第 2 行：缩进错误（与上方代码块的缩进不匹配，期望对齐到 0 个空格）
第 3 行:1：语法错误：期望 punct ":"，实际得到 newline
第 4 行:5：语法错误：意外的 token op "="
```

### 9.3 运行时错误（执行阶段）

脚本执行过程中由解释器抛出：

```
第 5 行：未定义的变量: foo
第 6 行：列表索引越界: 10（列表长度 3）
第 7 行：字符串索引越界: 5（字符串长度 3）
第 8 行：除零错误
第 9 行：对零取模错误
第 10 行：不能对 null 进行索引
第 11 行：尝试调用非函数值: "abc"
第 12 行：索引必须是数字或字符串，实际为 boolean
```

### 9.4 循环与中止错误

```
第 N 行：while 循环超过最大迭代次数 100000，可能存在无限循环
第 N 行：for 循环超过最大迭代次数 100000，可能存在无限循环
脚本已被手动中止           # 手动点击中止按钮
脚本执行超时（30秒），已被自动中止   # 超时自动中止
```

### 9.5 在编辑器中查看错误

- **实时诊断**：编辑器中以红色波浪线标注错误位置，鼠标悬停查看详细错误信息
- **状态栏**：顶部右侧显示当前错误数量（如「3 个错误」或「语法正确」）
- **运行时定位**：运行出错后，编辑器自动跳转光标到出错行

## 10. 定时任务

定时任务功能允许管理员设置自动定时执行的 CMD 命令，所有任务在后台线程中异步执行，不会阻塞 Web 请求。

### 10.1 访问方式

- 在 CMD 控制台页面点击「定时任务」按钮
- 直接访问 `/admin/cmd/scheduled`

### 10.2 调度模式

| 模式 | 说明 | 配置项 |
|------|------|--------|
| **间隔执行** | 每隔指定秒数重复执行 | 间隔秒数（支持快捷按钮：1分/1时/1天） |
| **每日定时** | 每天在固定时间执行一次 | 执行时间（HH:MM 格式） |
| **一次性执行** | 在指定日期时间执行一次后自动禁用 | 执行日期时间 |

### 10.3 创建任务

1. 点击「创建定时任务」按钮
2. 填写任务名称（如：每日备份）
3. 输入要执行的命令（如：`tar -czf /backup/data.tar.gz /data`）
4. 选择调度类型
5. 根据调度类型设置间隔或执行时间
6. 点击「保存」

### 10.4 任务管理

- **启用/禁用**：切换任务状态，禁用后不再自动执行
- **编辑**：修改任务配置，保存后重新计算下次执行时间
- **删除**：删除任务（相关日志保留）
- **立即执行**：手动触发任务立即执行，不影响原有调度
- **查看日志**：查看该任务的执行历史和输出

### 10.5 执行状态实时反馈

任务卡片底部显示「最近执行状态徽章」，无需手动刷新即可看到执行结果：

- **未执行**：灰色「未执行」提示
- **执行中**：蓝色「执行中…」徽章（手动触发或调度器刚启动任务时）
- **成功**：绿色徽章 + 开始时间 + 耗时
- **失败**：红色徽章 + 开始时间 + 耗时
- **活动中**：当任务在最近 10 分钟内有执行记录时，徽章右侧追加蓝色「活动中」标签

**刷新机制**：

- 页面每 15 秒自动通过 `/admin/cmd/scheduled/status` 接口拉取最新状态（轻量接口，仅返回状态信息）
- 仅更新状态徽章，不重渲染整个列表，避免打断用户操作
- 切回浏览器标签页时立即刷新一次
- 手动「立即执行」时立即显示「执行中」状态，并在 0.5s / 2s / 5s 后自动拉取最新结果
- 所有模态框打开时暂停自动刷新，关闭后恢复

### 10.6 执行日志

每次任务执行后自动记录以下信息：

| 字段 | 说明 |
|------|------|
| 任务名称 | 执行时的任务名称 |
| 命令 | 执行的命令 |
| 输出 | stdout + stderr（超过 10000 字符自动截断） |
| 退出码 | 命令退出码 |
| 状态 | 成功 / 失败 |
| 开始时间 | 执行开始时间 |
| 完成时间 | 执行完成时间 |
| 耗时 | 执行耗时（秒） |

### 10.7 配置

在 `config.py` 中可调整以下配置：

```python
TASK_SCHEDULER_INTERVAL = 10        # 调度器检查间隔（秒）
TASK_EXECUTION_TIMEOUT = 300        # 单个任务执行超时（秒）
TASK_EXECUTOR_POOL_SIZE = 4         # 执行线程池大小
```

## 11. 日志自动清除

系统自动管理日志表的大小，避免日志无限增长影响性能。

### 11.1 日志类型与上限

| 日志表 | 配置项 | 默认上限 | 说明 |
|--------|--------|----------|------|
| `access_logs` | `MAX_ACCESS_LOGS` | 500 | 访问日志 |
| `cmd_run_logs` | `MAX_CMD_LOGS` | 1000 | CMD 命令执行日志 |
| `scheduled_task_logs` | `MAX_TASK_LOGS` | 2000 | 定时任务执行日志 |

### 11.2 工作原理

- 后台线程每隔 `LOG_CLEANUP_INTERVAL`（默认 300 秒）检查一次各日志表
- 当某表记录数超过上限时，自动删除最旧的记录，使记录数回到上限
- 清理操作在后台线程中执行，不影响 Web 请求

### 11.3 修改配置

在 `config.py` 中修改对应的配置值即可：

```python
MAX_ACCESS_LOGS = 500          # 访问日志上限
MAX_CMD_LOGS = 1000            # CMD 命令日志上限
MAX_TASK_LOGS = 2000           # 定时任务日志上限
LOG_CLEANUP_INTERVAL = 300     # 清理检查间隔（秒）
```

## 12. 异步执行架构

为避免阻塞主进程（Web 请求处理），项目使用多种异步执行技术：

### 12.1 后台服务线程

| 服务 | 文件 | 职责 |
|------|------|------|
| 调度器 | [services/scheduler.py](file:///workspace/services/scheduler.py) | 每 10 秒扫描到期任务，通过线程池异步执行 |
| 日志清理器 | [services/log_cleaner.py](file:///workspace/services/log_cleaner.py) | 每 5 分钟检查日志表大小，删除超限旧记录 |
| 日志写入器 | [services/log_writer.py](file:///workspace/services/log_writer.py) | 通过队列批量异步写入访问日志 |

所有后台服务均为守护线程（daemon=True），随主进程退出。

### 12.2 异步 I/O 与多线程

| 场景 | 同步实现（阻塞） | 异步实现（非阻塞） |
|------|------|------|
| 访问日志写入 | 每请求直接 INSERT | 队列 + 后台线程批量写入 |
| IP 地理查询 | 同步请求 ip-api.com | 后台线程异步查询，请求时返回缓存 |
| CPU 使用率 | `psutil.cpu_percent(interval=0.5)` | `psutil.cpu_percent(interval=None)` |
| 命令执行 | 主线程阻塞等待 | `ThreadPoolExecutor` 异步执行 |
| 命令执行日志 | 同步写入数据库 | 后台线程写入 |
| 任务调度 | 阻塞主线程 | 后台线程扫描 + 线程池执行 |

### 12.3 数据库查询优化

为避免 N+1 查询问题，对社区页面和投票 API 进行了批量查询优化：

- **投票列表**：一次性获取所有选项、所有投票统计、当前用户的所有投票记录
- **留言板回复**：使用 SQLite 窗口函数 `ROW_NUMBER()` 一次性获取所有主题的最近 50 条回复
- **用户信息**：使用 Flask `g` 对象在单次请求内缓存，避免重复查询

优化前社区页面 N 个投票 + M 个主题需要 `1 + 3N + 2M` 次查询，优化后仅需 `4` 次查询（与 N、M 无关）。
